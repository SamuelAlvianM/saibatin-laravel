#  🔴 BERKAS INI TIDAK BOLEH BERISI NILAI ASLI. Yang ada di sini hanya NAMA
#     variabel dan penjelasannya; isi nilainya langsung di server. Aturan
#     journal induk §2 no. 6 — jangan menaruh rahasia di berkas mana pun yang
#     ikut repo.
#
#  🔴 `.env` lokal SENGAJA TIDAK diikutkan ke paket unggahan. Kalau ikut,
#     aplikasi produksi akan menunjuk `DB_HOST=127.0.0.1` dengan kredensial
#     laptop dan gagal terhubung — atau lebih buruk, tersambung ke database
#     lain yang kebetulan bernama sama.
#
# =============================================================================
#  MENGHUBUNGKAN KE DATABASE cPANEL — jawaban ringkasnya ada di lima baris
#  DB_* di bawah. Cara mendapatkan nilainya:
#
#   1. cPanel → MySQL® Databases → "Create New Database".
#      Namanya akan diberi awalan akun secara otomatis, mis. Anda mengetik
#      `saibatin` tetapi yang jadi adalah `namaakun_saibatin`.
#      🔴 Yang ditulis di DB_DATABASE adalah nama LENGKAP berawalan itu.
#
#   2. Di halaman yang sama → "Add New User". Sama, namanya berawalan:
#      `namaakun_saibatin`. Pakai sandi yang dibuat Password Generator.
#
#   3. "Add User To Database" → pilih user & database tadi → centang
#      **ALL PRIVILEGES**. Tanpa langkah ini, user-nya ada tapi tidak bisa
#      menyentuh apa pun, dan galatnya berbunyi "Access denied" — mudah
#      disalahartikan sebagai sandi salah.
#
#   4. DB_HOST tetap **127.0.0.1**. Di cPanel, MySQL berjalan di mesin yang
#      sama dengan PHP. Jangan diisi nama domain: itu memaksa koneksi keluar
#      lewat jaringan dan biasanya ditolak firewall.
#      (Kecuali paket Anda memakai "Remote MySQL" — hanya itu pengecualiannya.)
#
#   5. Mengisi datanya: ekspor DB lokal jadi .sql lalu impor lewat phpMyAdmin.
#      🔴 JANGAN `php artisan migrate:fresh` di server — perintah itu MENGHAPUS
#      seluruh tabel lebih dulu. Untuk DB yang tabelnya sudah ada, urutannya
#      `migrate:install` lalu menandai migration sebagai sudah jalan
#      (HANDOFF §5 no. 4).
#
#  Uji koneksinya SEBELUM membuka portal untuk warga:
#      cd ~/saibatin-app && php artisan db:show
#  Kalau tabelnya terdaftar, koneksinya benar.
# =============================================================================
